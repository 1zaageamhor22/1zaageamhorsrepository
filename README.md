# Random Password Generator
**Автор:** Гурмеков Амир 

## Описание программы 
*"Random Password Generator — это GUI-приложение для генерации случайных паролей с возможностью настройки длины и типа символов (буквы, цифры, спецсимволы). Позволяет быстро создавать надежные пароли, сохранять историю генерации и при необходимости использовать её повторно."*

## Возможности
- ✅ Генерация паролей — создание случайных паролей заданной длины
- ✅ Настройка параметров — выбор использования цифр, букв
- ✅ Ползунок длины — удобная настройка длины пароля в заданном диапазоне
- ✅ Валидация данных — проверка минимальной и максимальной длины пароля, а также наличия выбранных типов символов
- ✅ История генерации — автоматическое сохранение всех паролей в JSON-файл
- ✅ Загрузка истории — восстановление ранее сгенерированных паролей при запуске приложения
- ✅ Табличное отображение — удобный просмотр истории паролей в виде таблицы

## Требования для запуска
Что нужно установить на компьютер:  
- Python 3.10 или выше  
- Библиотеки: `pip install tk`

## Как запустить
```bash
python main.py
```
